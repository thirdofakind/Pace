## Technical Details

This section provides technical information for developers and contributors.

### Architecture

Pace is built using a modern web stack, utilizing **Vite** as the build tool and development server for an optimized development experience.

### Prerequisites

Ensure you have the following installed before proceeding:
* Node.js (version 18+ recommended)
* npm or yarn

### Installation & Running Locally

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Project Structure
* `src/`: Contains the application source code.
* `release/`: Contains production build artifacts.
* `node_modules/`: Project dependencies.

### Scripts
* `npm run dev`: Starts the local development server.
* `npm run build`: Creates a production-ready build.
